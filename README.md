# CS487-finance-management-system

Group Members: David Rivera Chino, Jasia Ernest, Sannan Khalid, Xing Chen
Programming language used: Python
Technologies used: PyQt6, SQLite, Matplotlib

## Features
- Financial Tracking: Add, edit, delete income and expenses, categorize transactions, view spending trends
- Budget Management: Set budgets by category, track progress, alerts for overspending
- Bills & Reminders: Add, edit, delete bills, reminders, automatic bill deduction
- Investment Tracking: Track investments with compound rate, display graphs
- Financial Health Monitoring: Generate health score, detect unusual spending, provide insights

## Installation
1. Install dependencies: pip install PyQt6 matplotlib
2. Run: python app.py
